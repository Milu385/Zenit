# H-055 · Cuestionario SUS (System Usability Scale)

Las diez afirmaciones estándar de la escala SUS (Brooke, 1996), en español, con respuesta de 1 a 5:

- 1 = Totalmente en desacuerdo
- 5 = Totalmente de acuerdo

Se responde justo después de terminar las tareas, sin conversar antes con el facilitador.

**Para el formulario (Google Forms o Microsoft Forms):**
- Una pregunta de "escala lineal" de 1 a 5 por afirmación, todas obligatorias, en este orden y sin cambiar el texto.
- Agregar al inicio un campo "Código de participante" (P1 a P7). No se piden el nombre ni el correo.
- Texto de introducción: "Responde pensando en lo que acabas de hacer con Zenit. No hay respuestas correctas; marca tu primera impresión."

| # | Afirmación |
|---|---|
| 1 | Creo que me gustaría usar este sistema con frecuencia. |
| 2 | Encontré el sistema innecesariamente complejo. |
| 3 | Pensé que el sistema era fácil de usar. |
| 4 | Creo que necesitaría el apoyo de una persona con conocimientos técnicos para poder usar este sistema. |
| 5 | Encontré que las distintas funciones del sistema estaban bien integradas. |
| 6 | Pensé que había demasiada inconsistencia en el sistema. |
| 7 | Imagino que la mayoría de las personas aprendería a usar este sistema muy rápido. |
| 8 | Encontré el sistema muy engorroso de usar. |
| 9 | Me sentí muy seguro(a) usando el sistema. |
| 10 | Necesité aprender muchas cosas antes de poder empezar a usar este sistema. |

## Cálculo del puntaje

- Afirmaciones impares (1, 3, 5, 7, 9): respuesta − 1.
- Afirmaciones pares (2, 4, 6, 8, 10): 5 − respuesta.
- Puntaje SUS = suma de las diez contribuciones × 2,5, en una escala de 0 a 100.

Comprobaciones, que también están en la hoja de cálculo (`calculo-sus.xlsx`, hoja "Comprobaciones"):
- Todo en 3: cada contribución vale 2; 20 × 2,5 = **50**.
- El mejor caso (5 en las impares y 1 en las pares): cada contribución vale 4; 40 × 2,5 = **100**.
- El peor caso (1 en las impares y 5 en las pares): **0**.

## Referencia

Brooke, J. (1996). SUS: A "quick and dirty" usability scale. En P. W. Jordan, B. Thomas, B. A. Weerdmeester y I. L. McClelland (Eds.), *Usability evaluation in industry* (pp. 189–194). Taylor & Francis.
