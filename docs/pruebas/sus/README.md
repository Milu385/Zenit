# H-055 · Preparación de la prueba de usabilidad (SUS)

| Archivo | Qué es |
|---|---|
| `tareas.md` | Las 5 tareas guiadas sobre las pantallas 1 a 4 (y costos), cada una con su criterio de éxito y su tiempo límite |
| `cuestionario.md` | Las 10 afirmaciones SUS en español, escala de 1 a 5, cómo armar el formulario y cómo se calcula el puntaje (Brooke, 1996) |
| `calculo-sus.xlsx` | Hoja "Respuestas": puntaje por participante y promedio, con fórmulas. Hoja "Comprobaciones": todo en 3 da 50, el mejor caso da 100 y el peor da 0. Hoja "Participantes": 7 filas (5 titulares y 2 suplentes) para el nombre, el perfil y la hora confirmada |
| `guion.md` | El guion del facilitador: qué decir al empezar, no ayudar, qué anotar y el consentimiento para tomar notas |

## Lo que hace Daniel

1. **Formulario.** Crear el formulario SUS en Google Forms o Microsoft Forms con el texto de `cuestionario.md`, y poner el enlace aquí: `(pendiente)`.
2. **Participantes.** Conseguir 7 personas con perfil técnico (5 titulares y 2 suplentes), confirmar la hora con cada una y llenar la hoja "Participantes".
3. **Datos para las tareas.** Antes de cada sesión, pedir a Juan José un incidente abierto de severidad alta con hipótesis para las tareas 2 a 4, y un usuario `operador` y uno `finanzas` para la prueba.
4. Correr las sesiones con `guion.md` y pasar las respuestas a `calculo-sus.xlsx`.

Esta preparación no depende del congelamiento: no toca el código.
